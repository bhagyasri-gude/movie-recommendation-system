# Movie Recommendation System 🎬

A Machine Learning-based Content-Based Movie Recommendation System built using Python and Streamlit.

## 📌 Project Overview
This application recommends movies based on user selection by analyzing similarity between movie overviews, genres, and metadata from the TMDB 5000 Dataset.

## 🛠️ Tech Stack & Algorithms
- **Language:** Python
- **Libraries:** Pandas, Scikit-learn, Streamlit
- **Algorithm:** Content-Based Filtering using TF-IDF Vectorization & Cosine Similarity

## 🚀 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/bhagyasri-gude/movie-recommendation-system.git](https://github.com/bhagyasri-gude/movie-recommendation-system.git)
   cd movie-recommendation-system
2. ** Install required packages**
   pip install pandas scikit-learn streamlit
3.** Run the streamlit app**
   streamlit run app.py
